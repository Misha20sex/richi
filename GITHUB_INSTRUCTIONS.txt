  ИНСТРУКЦИЯ: Автоматическая сборка JAR через GitHub
═══════════════════════════════════════════════════════════

ШАГ 1: Создайте аккаунт на GitHub
→ Откройте: https://github.com/signup
→ Зарегистрируйтесь (email, пароль, имя пользователя)
→ Подтвердите email

ШАГ 2: Создайте новый репозиторий
→ Нажмите зеленую кнопку "New" (вверху слева)
→ Repository name: reach-mod
→ Public (оставьте как есть)
→ Нажмите "Create repository"

ШАГ 3: Загрузите файлы
→ Нажмите "uploading an existing file"
→ Перетащите ВСЕ файлы из этой папки:
   - ReachMod.java
   - ReachConfig.java
   - ReachHandler.java
   - ReachGui.java
   - build.gradle
   - mods.toml
   - setup_project.bat
   - gradlew
   - .github/workflows/build.yml (ВАЖНО!)

→ Нажмите "Commit changes"

ШАГ 4: GitHub автоматически соберет JAR!
→ Перейдите во вкладку "Actions" (вверху)
→ Увидите процесс сборки с желтым кружком 🟡
→ Дождитесь зеленой галочки ✅ (2-5 минут)
→ Кликните на название сборки
→ Внизу увидите "Artifacts" → "ReachMod-JAR"
→ СКАЧАЙТЕ ZIP файл
→ Внутри будет готовый .jar файл!

ШАГ 5: Установите мод
→ Скопируйте .jar в папку: .minecraft/mods/
→ Запустите Minecraft 1.16.5 с Forge
→ Готово!
